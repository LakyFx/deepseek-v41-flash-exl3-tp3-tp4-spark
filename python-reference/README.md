# Browsable historical Triton generators

These three source files are exact copies from the already published,
hash-pinned `tensorfold/artifacts/tensorfold-rope-reference.tar.gz`. Their
original TensorFold Apache-2.0 license is retained here. The copy is for review;
it is **not the complete importable package**.

For compilation, extract the full package using `tensorfold/extract.py` and
follow [the AOT source rebuild guide](../docs/AOT-SOURCE-REBUILD.md).
That guide includes the separate TP3 generator and the 1.2.8 additions.
